# obsidian-bib-sync

Syncs Obsidian paper notes (YAML frontmatter) to identical managed blocks in many `.bib` files. CLI command: `obib`.

**Review `PLAN.md` before each work session and at the start/end of each milestone; update its Decisions and Status sections whenever a decision changes.**

## Commands
- `uv sync` — install deps
- `uv run pytest` — tests
- `uv run ruff check . && uv run ruff format --check .` — lint
